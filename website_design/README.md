## 2. Фирменная дизайн-система (Design System Tokens)

### Цветовая палитра:
| Токен | HEX / RGBA | Назначение в интерфейсе |
| :--- | :--- | :--- |
| **Primary Navy** | `#0b1329` | Глубокий премиальный темно-синий фон страницы |
| **Card Navy** | `rgba(15, 23, 42, 0.75)` | Полупрозрачный фон карточек со стеклянным размытием |
| **Accent Gold** | `#f59e0b` | Золотой акцентный цвет (кнопки, активные вкладки, иконки) |
| **Gold Hover** | `#d97706` | Темно-золотой при наведении курсора |
| **Emerald Success** | `#10b981` | Зеленый цвет подтверждений, статусов «Онлайн», бейджей |
| **Text Primary** | `#ffffff` | Основные заголовки и важные цифры |
| **Text Muted** | `#94a3b8` | Вторичный текст, подписи характеристик, подсказки |
| **Border Glass** | `rgba(255, 255, 255, 0.1)` | Тонкие границы карточек с легким свечением |

### Типографика:
* **Заголовки (H1-H3):** `Outfit` / `Montserrat` — строгие геометрические гротески с выразительным начертанием (Font Weight: 700 / 800).
* **Основной текст и цифры:** `Inter` — читабельный шрифт интерфейсов с отличным рендерингом на экранах мобильных устройств.

### Визуальные эффекты:
* **Glassmorphism:** `backdrop-filter: blur(16px); -webkit-backdrop-filter: blur(16px);`
* **Тонкие рамки с градиентом:** `box-shadow: 0 20px 50px rgba(0, 0, 0, 0.5);`
* **Микроанимации:** Плавный hover `transform: translateY(-4px)`, мерцающие индикаторы статусов, акцентные полосы прогресса.

## 3. Обзор интерактивных блоков

### А. Полноэкранный кастомный слайдер (`caravan_services_studio.html`)
Разработан специально для преодоления ограничений стандартных слайдеров Tilda.
* **Особенности:**
  1. Выводит 6 услуг компании с большими фоновыми фото, характеристиками (метрики скорости, грузоподъемности, географии).
  2. Интерактивная навигация: перелистывание стрелками, точками пагинации, мини-превью внизу и свайпом на смартфонах.
  3. Динамические теги: фильтрация услуг по категориям (*«Все», «Ж/Д», «Срочные», «Мультимодал»*).
  4. Модальное окно «Подробнее»: детальные спецификации вагонов, допустимые габариты, требования к грузу.
  5. Кнопка «Заказать расчет»: открывает виджет или перенаправляет в Telegram-бота.

### Б. Плиточный блок услуг для Tilda (`tilda_services_tile_block.html`)
Компактный и эстетичный блок из 6 плиток для размещения в основном теле лендинга:
* Эффект «глубокого стекла» и неонового контура при наведении.
* Готовые иконки для каждой услуги.
* Кнопка быстрой связи.

### В. Виджет калькулятора и отслеживания (`caravan-tracking-widget.html`)
Автономный виджет, который можно встроить как:
1. Плавающую круглую кнопку в правом нижнем углу сайта (FAB).
2. Или статичный блок-калькулятор на отдельной странице.
* **Функционал:**
  * Живой поиск станций СНГ с автоподстановкой по базе 1520 мм.
  * Мгновенный расчет индикативной ставки в USD.
  * Сбор контактных данных (Телефон, Организация, Email).
  * Прямая передача заявки в Google Таблицу и Telegram-группу менеджеров.

## 5. Пошаговая инструкция по внедрению в Tilda

### Как вставить кастомный слайдер или плитку в Tilda:
1. Откройте страницу сайта в редакторе Tilda.
2. Добавьте блок **T123 («HTML-код»)** из категории *«Другое»*.
3. Нажмите кнопку **«Контент»** в блоке T123.
4. Откройте файл `website_design/tilda_services_tile_block.html` (или `tilda-embed-snippet.html`), скопируйте весь код и вставьте в поле HTML-кода.
5. Нажмите **«Сохранить и закрыть»** и опубликуйте страницу.
6. Блок автоматически адаптируется под ширину контейнера Tilda (1200px) и под мобильные экраны.
