# Руководство по интеграции виджета Caravan Railroad в Tilda

Этот гайд поможет вам за 2 минуты встроить разработанный интерактивный модуль дислокации, личного кабинета и динамических счетчиков в ваш сайт на Тильде.

---

## Вариант 1: Вставка через стандартный блок T123 (Самый простой и быстрый)

Этот способ подходит, если вы хотите встроить готовый блок под вашим меню или баннером.

1. Откройте нужную страницу в редакторе **Tilda**.
2. В месте, где должен быть блок дислокации, нажмите **«+» (Добавить блок)**.
3. В левом меню категорий выберите категорию **«Другое»** ➔ блок **«T123 HTML-код»**.
4. Наведите на добавленный блок и нажмите кнопку **«Контент»**.
5. Откройте в текстовом редакторе файл [caravan-tracking-widget.html](file:///Users/asilbek/Documents/CaravanRailRoad/caravan-tracking-widget.html), скопируйте весь его текст целиком и вставьте в поле блока T123.
6. Нажмите **«Сохранить и закрыть»**.
7. Нажмите **«Опубликовать»** страницу (в самом редакторе Тильды скрипты не исполняются в целях безопасности, результат виден на опубликованной странице или по ссылке предпросмотра).

---

## Вариант 2: Вставка внутрь Zero Block (Для уникального авторского дизайна первого экрана)

Если вы делаете первый экран в **Zero Block** (свои фоновые картинки, поезда, 3D-графика, нестандартные кнопки):

1. Откройте ваш **Zero Block** в режиме редактирования (**«Редактировать блок»**).
2. Нажмите в левом верхнем углу **«+» (Add element)** ➔ выберите **«Add HTML»** (добавится элемент с кодом).
3. Кликните дважды по добавленному HTML-элементу (или нажмите на него и откройте правую панель настроек).
4. В поле ввода кода вставьте весь код из файла [caravan-tracking-widget.html](file:///Users/asilbek/Documents/CaravanRailRoad/caravan-tracking-widget.html).
5. В правой панели Zero Block настройте размеры HTML-контейнера:
   * **Width**: `100%` (или `1160px` для фиксации по сетке контейнера).
   * **Height**: задайте высоту от `550px` до `750px` (чтобы карточка не перекрывала нижние элементы).
   * **Align**: по центру экрана (`Grid Container: Center`).
6. Сохраните изменения в Zero Block и опубликуйте страницу.

## Логика доступа и защита дислокации (B2B Контур)

По требованию коммерческой безопасности, вкладка **«Быстрый трекинг»** защищена:
1. **Для неавторизованных пользователей (гостей):** отображается экран ограничения доступа с предложением войти в личный кабинет или зарегистрировать компанию.
2. **После авторизации (входа в кабинет):**
   * Отображается статус контрагента и кнопки быстрого выбора **только его собственного подвижного состава**.
   * При вводе номера прикрепленного вагона/контейнера отображается полный маршрут и статус дислокации.
   * Если пользователь пытается ввести номер чужого вагона (не прикрепленного к его компании) — система выводит уведомление: **«Доступ ограничен: транспорт не числится за вашей организацией»**.
3. **После регистрации:** новая компания автоматически авторизуется, получает тестовый прикрепленный вагон и может сразу отслеживать свои грузы.

## Как подключить ваши реальные данные из Google Таблицы / Excel

В коде виджета предусмотрено автоматическое переключение:
* **Пока вы не указали ссылку** — сайт работает в **демо-режиме** с защищенной авторизацией и проверкой прав.
* **Как только вы опубликовали скрипт в Google Таблице:**
  1. В коде блока найдите строчку (примерно в секции `<script>`):
     ```javascript
     var CARAVAN_CONFIG = {
       apiUrl: "", // ВСТАВЬТЕ СЮДА ВАШУ ССЫЛКУ ИЗ GOOGLE APPS SCRIPT
       enableAnimation: true
     };
     ```
  2. Вставьте туда ссылку на ваше развернутое веб-приложение:
     ```javascript
     var CARAVAN_CONFIG = {
       apiUrl: "https://script.google.com/macros/s/AKfycbxXXXXXXXXX/exec",
       enableAnimation: true
     };
     ```
  3. Сохраните и опубликуйте в Тильде — данные по вагонам, клиентам и 3 цифрам статистики начнут загружаться напрямую из вашей таблицы!

## Настройка прозрачности и фирменных цветов Caravan Railroad

Модуль спроектирован так, чтобы идеально ложиться поверх фоновых фотографий и баннеров в Tilda (Zero Block или T123) без лишних квадратных рамок:
* **Основной контейнер `#caravan-tracking-root`** полностью прозрачный (`background: transparent !important; padding: 0 !important;`).
* **Внутренние карточки (`.cr-stats-bar`, `.cr-card`)** имеют эффект **Glassmorphism** (полупрозрачный матовый фон `backdrop-filter: blur(20px)`), что гарантирует четкую читаемость текста и полей ввода на фоне любого изображения.

Если вы захотите изменить прозрачность или фирменные акценты, в начале секции `<style>` в файле виджета есть блок CSS-переменных:

```css
#caravan-tracking-root {
  --cr-bg-main: transparent;             /* Прозрачный базовый контейнер */
  --cr-bg-card: rgba(15, 26, 48, 0.88);  /* Полупрозрачный фон карточки (блюр поверх фото) */
  --cr-bg-input: rgba(10, 17, 32, 0.85); /* Фон полей ввода */
  --cr-amber: #F59E0B;                   /* Фирменный желто-оранжевый акцент */
  --cr-amber-hover: #D97706;             /* Акцент при наведении */
  --cr-emerald: #10B981;                 /* Зеленый статус "В движении" */
  --cr-font: 'Inter', sans-serif;        /* Шрифт (можно указать шрифт вашего сайта) */
}
```
