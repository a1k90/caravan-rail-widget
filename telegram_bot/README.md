# 🚂 Caravan Railroad — Telegram Assistant Bot

Официальный Telegram-бот компании **Caravan Railroad & Multimodal Logistics** для автоматизации приема заявок на перевозку грузов, аренду подвижного состава, расчет железнодорожных тарифов, авто-, авиа-, мультимодальные перевозки и таможенное оформление.

Бот собирает структурированные данные клиентов и направляет детальный коммерческий бриф в отдел логистики на корпоративную почту **`info@caravanrailroad.com`**, а также сохраняет заявки в базе данных **SQLite**.

---

## 🌟 Возможности бота

1. **Мультиязычность (3 языка):**
   - 🇷🇺 Русский
   - 🇬🇧 English
   - 🇨🇳 中文 (Simplified Chinese)
   - Мгновенное переключение языка в любой момент через меню или команду `/lang`.

2. **Корпоративная регистрация клиентов:**
   - Передача номера телефона в один клик (кнопка Telegram `request_contact`) или ввод вручную в международном формате.
   - Сбор ФИО контактного лица.
   - Фиксация наименования организации / компании.
   - Корпоративный Email с валидацией формата.
   - Данные сохраняются в SQLite: повторно вводить при новых заявках не требуется.
   - Возможность редактирования профиля через команду `/profile`.

3. **6 специализированных пошаговых опросников (Wizards):**
   - 🚂 **Ж/Д перевозки и Аренда вагонов (1520 & 1435 мм):**
     - Выбор услуги: Расчет тарифа & перевозка ИЛИ Аренда подвижного состава.
     - Станция отправления и назначения (наименование или 6-значный код станции).
     - Наименование груза (ЕТСНГ / ГНГ).
     - Тип подвижного состава: Крытые (138-161 м³), Полувагоны, Платформы (универсальные/фитинговые), Цистерны, Хопперы (зерновозы/минераловозы), Контейнеры (20/40 фут).
     - Предоставление парка: Вагоны Caravan Railroad (включить в ставку) или Собственный/арендованный парк клиента.
     - Объем (вагоны, тонны).
     - Особые требования и примечания.
   - 🚛 **Автомобильные перевозки:**
     - Город/страна погрузки и выгрузки.
     - Тип автотранспорта (Тент стандарт 86-92 м³, Мегатрейлер 100-120 м³, Рефрижератор, Трал для негабарита, Контейнеровоз).
     - Вес (т) и объем (м³).
     - Дата готовности груза к перевозке.
   - ✈️ **Международные авиаперевозки:**
     - Аэропорт/город вылета и прилета.
     - Характер груза (Генеральный, Опасный DGR, Температурный/Pharma, Экспресс/Чартер).
     - Вес брутто и габариты мест (Д×Ш×В).
     - Необходимость забора со склада (Pick-up).
   - 🚢 **Мультимодальные перевозки:**
     - Маршрут (Откуда ➔ Куда).
     - Логистическая схема (Море+ЖД, Авто+ЖД, ТМТМ/Средний коридор через Каспий).
     - Тип контейнеров (20'DC, 40'HC, 40'RF).
     - Количество контейнеров и вес.
   - 📑 **Таможенное оформление (ВЭД брокер):**
     - Страна и таможенный пост (Алтынколь, Достык, Астана и др.).
     - Таможенный режим (Импорт ИМ-40, Экспорт ЭК-10, Транзит ТР-80).
     - Описание товара и код ТН ВЭД.
     - Сертификация (СТ-1, фито, вет, ЕАЭС).
   - 🌐 **Транзитное ж/д экспедирование:**
     - Железные дороги следования (КЗХ, РЖД, УТИ, ТДЖ, ГРЗ).
     - Погранпереходы и стыковые станции (Достык, Сарыагаш, Илецк).
     - Требуемые сервисы (оплата тарифа, охрана, слежение, перегруз).

4. **Генерация уникального номера заявки:**
   - Каждая заявка получает сквозной корпоративный номер вида: `CR-2026-1001`, `CR-2026-1002`...

5. **Отправка на почту `info@caravanrailroad.com`:**
   - Фирменное HTML-письмо с таблицей данных и стилизацией Caravan Railroad.
   - Текстовая версия для любых почтовых клиентов.
   - Отказоустойчивость: если SMTP не настроен, заявка надежно сохраняется в локальный лог `telegram_bot/logs/emails.log` и базу данных SQLite — ни один клиент не потеряется.

6. **Уведомление клиента:**
   - После подтверждения клиент получает сообщение с номером заявки, датой и контактами менеджера.

## 🚀 Инструкция по запуску

### Шаг 1. Получение токена бота в Telegram
1. Откройте Telegram и найдите официального бота **`@BotFather`**.
2. Отправьте команду `/newbot`.
3. Укажите имя бота (например: `Caravan Railroad Logistics`).
4. Укажите username бота (например: `caravan_railroad_bot` или `caravan_logistics_bot`).
5. Скопируйте полученный **API Token** (вида `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`).

### Шаг 2. Настройка команд в @BotFather (рекомендуется)
Отправьте боту `@BotFather` команду `/setcommands`, выберите вашего бота и отправьте список команд:
```text
start - Запуск бота / Главное меню
leads - Мои заявки
profile - Мой профиль клиента
about - О компании и Контакты
lang - Сменить язык (Language)
cancel - Отмена текущего действия
```

### Шаг 3. Установка токена в `.env`
Откройте файл `telegram_bot/.env` и вставьте ваш токен:
```env
TELEGRAM_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
MANAGER_EMAIL=info@caravanrailroad.com
DEFAULT_LANGUAGE=ru
```

*(Опционально)* Если вы хотите, чтобы письма физически отправлялись через ваш почтовый сервер по SMTP, укажите параметры в `.env`:
```env
SMTP_HOST=smtp.yandex.com
SMTP_PORT=465
SMTP_USER=leads@caravanrailroad.com
SMTP_PASSWORD=ваш_пароль_приложения
SMTP_USE_SSL=True
```
*Если SMTP не заполнен, бот все равно работает на 100%, сохраняя заявки в базу SQLite и в файл `logs/emails.log`.*

### Шаг 4. Проверка тестов
Перед запуском можно выполнить автотесты:
```bash
python3 -m unittest telegram_bot.test_bot_modules -v
```
Все 6 тестов должны завершиться статусом `OK`.

### Шаг 5. Запуск бота
Запустите бота из корневой папки проекта:
```bash
python3 -m telegram_bot.bot
```

## 🔄 Фоновый запуск на сервере (Daemon)

### Вариант А: Запуск через `nohup`
```bash
nohup python3 -m telegram_bot.bot > telegram_bot/logs/bot.log 2>&1 &
```

### Вариант Б: Запуск через `systemd` (Linux / VPS)
Создайте файл сервиса `/etc/systemd/system/caravan-bot.service`:
```ini
[Unit]
Description=Caravan Railroad Telegram Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/path/to/CaravanRailRoad
ExecStart=/usr/bin/python3 -m telegram_bot.bot
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
Активируйте и запустите:
```bash
systemctl daemon-reload
systemctl enable caravan-bot
systemctl start caravan-bot
systemctl status caravan-bot
```
