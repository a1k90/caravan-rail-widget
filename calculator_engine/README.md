## 2. 6 направлений расчета и математические формулы

### Модуль 1. Ж/Д логистика (колея 1520 мм, МТТ/ТП РЖД/КТЖ/УТИ)
* **Канонические маршруты и верифицированные расстояния:**
  1. `Илецк-1 (эксп.) [666501]` ➔ `Сарыагаш (эксп.) [704101]`: **2 080 км** (Транзит КТЖ).
  2. `Озинки (эксп.) [660008]` ➔ `Сарыагаш (эксп.) [704101]`: **2 150 км** (Транзит КТЖ).
  3. `Озинки (эксп.) [660008]` ➔ `Бейнеу (эксп.) [660309]`: **1 480 км** (Транзит КТЖ на Туркменистан).
  4. `Петропавловск [680007]` ➔ `Сарыагаш (эксп.) [704101]`: **1 680 км**.
  5. `Семей [709406]` ➔ `Чукурсай [720000]`: **1 850 км (КТЖ) + 24 км (УТИ)** — трехплечевой расчет с погранстыком.
* **Формула расчета ж/д тарифа:**
  $$\text{Тариф} = \text{Базовая ставка}(d, w) \times K_{\text{груз}} \times K_{\text{вагон}} \times K_{\text{маршрут}} + \text{Сборы станционные} + \text{Охрана}$$
  * $d$ — расстояние в км по тарифному руководству № 4.
  * $w$ — расчетная масса груза (с учетом грузоподъемности и минимальной весовой нормы).
  * $K_{\text{груз}}$ — тарифный класс (1 класс — сырье, 2 класс — зерно/прокат, 3 класс — готовая продукция/химия).
  * $K_{\text{вагон}}$ — коэффициент принадлежности вагона (ПВ — приватный парк со скидкой, СП — инвентарный парк дороги).

---

### Модуль 2. Аренда подвижного состава (Fleet Leasing)
Расчет суточной аренды и кругорейса вагонного парка Caravan Railroad:
* **Типы парка в системе:**
  1. **Хопперы-зерновозы:** объем 105–120 м³, грузоподъемность 70–72 т.
  2. **Крытые вагоны:** объем 138, 158, 161 м³, грузоподъемность 68 т.
  3. **Полувагоны (Люковые):** объем 85–92 м³, г/п 70 т.
  4. **Платформы:** универсальные и 80-футовые фитинговые контейнеровозы.
  5. **Цистерны:** нефтебензиновые, химические, пищевые (патока, растительное масло).
* **Формула кругорейса:**
  $$\text{Стоимость аренды} = N_{\text{вагонов}} \times \left( \frac{2 \times \text{Дистанция}}{V_{\text{сутки}}} + T_{\text{погрузка}} + T_{\text{выгрузка}} + T_{\text{стык}} \right) \times \text{Суточная ставка}$$
  * $V_{\text{сутки}}$ — нормативная скорость движения (300-350 км/сутки для повагонных отправок, 450-550 км/сутки для маршрутных поездов).

---

### Модуль 3. Международные автоперевозки
* **Типы автопоездов:**
  * Тент 86–92 м³ (до 22 тонн).
  * Мега / Сцепка 100–120 м³ (до 20 тонн, объемные грузы).
  * Рефрижератор (температурный режим -20°C ... +20°C, FRC).
  * Трал низкорамный (негабаритная спецтехника, г/п до 60 т).
* **Формула автотарифа:**
  $$\text{Фрахт} = (\text{Дистанция км} \times \text{Ставка EUR/км}) + \text{Сбор погранперехода} + \text{Разрешения Дозвол} + \text{Конвой (при необходимости)}$$

---

### Модуль 4. Авиаперевозки (IATA Chargeable Weight)
* **Правило объемного веса IATA:**
  $$\text{Объемный вес (кг)} = \frac{\text{Длина (см)} \times \text{Ширина (см)} \times \text{Высота (см)}}{6000}$$
  $$\text{Оплачиваемый вес (Chargeable Weight)} = \max(\text{Фактический вес брутто}, \text{Объемный вес})$$
* **Категории груза:** Генеральный, Опасный (DGR по классам 1-9), Скоропортящийся (PER), Фармацевтический (PIL/COL).

---

### Модуль 5. Мультимодальные контейнерные перевозки
* **Стандарты:** 20'GP (до 24 т), 40'GP (до 28 т), 40'HC (до 28 т, высота 2.9 м).
* **Схемы собственности:**
  * **COC (Carrier-Owned):** Контейнер морской линии / оператора.
  * **SOC (Shipper-Owned):** Контейнер грузовладельца.
* **Суммарный интермодальный фрахт:**
  $$\text{Total} = \text{Морской фрахт} + \text{THC (порт перевалки)} + \text{Ж/Д платформа} + \text{Дроп-офф контейнера} + \text{Автодоставка первой/последней мили}$$

---

### Модуль 6. Таможенный калькулятор (АИС «Таможня» / ТН ВЭД)
В базе данных `caravan_logistics.db` содержится **13 140 кодов ТН ВЭД ЕАЭС / Узбекистана**:
* **Формула расчета таможенных платежей (Импорт ИМ-40):**
  1. Таможенная стоимость = $\text{Цена товара (Инвойс)} + \text{Транспортные расходы до границы}$
  2. Таможенный сбор = Фиксированная ставка по шкале стоимости (ПКМ РУз).
  3. Ввозная пошлина = $\text{Таможенная стоимость} \times \text{Ставка пошлины (0–30\%)}$
  4. Акциз (для подакцизных) = $(\text{Таможенная стоимость} + \text{Пошлина}) \times \text{Ставка акциза}$
  5. НДС (12% в Узбекистане, 20% в РФ/КЗ) = $(\text{Таможенная стоимость} + \text{Пошлина} + \text{Акциз}) \times 12\%$
* **Smart Checklist документов:**
  В зависимости от кода система автоматически формирует перечень:
  * Сертификат соответствия / Декларация.
  * Фитосанитарный / Ветеринарный сертификат.
  * Сертификат происхождения СТ-1 / Form A.
  * Лицензия Минтранса / Минздрава.

## 3. Справочник REST API эндпоинтов

Все методы поддерживают как `GET` (query params), так и `POST` (JSON body):

| Метод | URL | Описание | Пример параметров |
| :--- | :--- | :--- | :--- |
| `GET/POST` | `/api/calculate/rail` | Расчет ж/д ставки по станциям | `from=666501&to=704101&weight=60&cargo=110100&wagon=covered` |
| `GET/POST` | `/api/calculate/fleet` | Расчет аренды вагонного парка | `wagon_type=grain&count=10&rent_days=30&rent_type=daily` |
| `GET` | `/api/stations` | Живой автокомплит станций 1520 мм | `q=Ташкент&limit=10` |
| `GET` | `/api/cargo` | Поиск груза по наименованию / ЕТСНГ | `q=Пшеница&limit=10` |
| `GET` | `/api/customs/search` | Поиск ставок по ТН ВЭД | `q=8703&limit=10` |

## 4. Как протестировать точность расчетов

```bash
# 1. Запуск канонического теста (Илецк - Сарыагаш, Семей - Чукурсай)
python3 calculator_engine/test_canonical.py

# 2. Тестовый запрос расчета ж/д тарифа к серверу
curl -s "https://caravan-rail-widget.onrender.com/api/calculate/rail?from=666501&to=704101&weight=60&cargo=110100&wagon=covered"

# 3. Тестовый поиск по базе 13 140 кодов ТН ВЭД
curl -s "https://caravan-rail-widget.onrender.com/api/customs/search?q=100199&limit=5"
```
