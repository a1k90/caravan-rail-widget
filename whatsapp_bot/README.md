## 1. Хроника операций и ключевые выводы (История проекта)

### Этап 1. Первая попытка через Green-API (Личный номер директора)
* **Что было сделано:** Был создан инстанс Green-API и отсканирован QR-код со смартфона директора (`+998 90 971 56 70`).
* **Что пошло не так:** Поскольку это был основной личный номер директора, бот перехватывал абсолютно все входящие сообщения (от друзей, семьи, коллег) и присылал им приветствие компании и выбор языка.
* **Решение:** Сессия была немедленно принудительно отключена (`logoutProcess`).
* **⚠️ КРИТИЧЕСКОЕ ПРАВИЛО НА БУДУЩЕЕ:** Никогда не сканировать QR-код бота с личного номера сотрудников или руководства! Всегда использовать отдельную выделенную SIM-карту / корпоративный номер.

## 3. Структура файлов в папке `whatsapp_bot/`

```text
whatsapp_bot/
├── __init__.py           # Экспорт основных методов модуля
├── config.py             # Настройки провайдеров, токены, пауза, телефоны
├── api_client.py         # Универсальный многопровайдерный клиент (Meta Cloud API, Green-API, Twilio, Simulation)
├── bot.py                # Ядро FSM бота: 6 калькуляторов, мультиязычность, регистрация, пуш в CRM
├── formatter.py          # Конвертация Markdown в синтаксис WhatsApp (*жирный*, _курсив_), нумерованные меню
└── README.md             # Настоящий документ (Полный архив и инструкция по запуску)
```

### Назначение ключевых компонентов:
1. **`bot.py`**:
   * Реализует пошаговые сценарии (мастера заявок) для 6 услуг компании:
     1. Ж/Д перевозка и аренда вагонов (Хопперы, крытые, полувагоны, платформы, цистерны).
     2. Автомобильные перевозки (Тенты 86-120 м³, рефрижераторы, тралы).
     3. Авиаперевозки грузов.
     4. Мультимодальные контейнерные перевозки (20'/40' HC).
     5. Таможенный брокер (ИМ-40, ЭК-10, ТР-80).
     6. Ж/Д экспедирование по администрациям (КТЖ, УТИ, ТДЖ, ТРК, РЖД).
   * Сохраняет клиентов и заявки в SQLite (`wa_users`, `leads`).
   * Синхронизирует профиль с **Google Таблицей** (`sync_user_to_sheets`).
   * Мгновенно отправляет сформированную заявку в Telegram-группу менеджеров `CaravanRailRoad_chat` (`-5521386609`).
   * Отправляет корпоративное письмо на `info@caravanrailroad.com`.
2. **`api_client.py`**:
   * Автоматически определяет активный шлюз.
   * Нормализует узбекские и международные телефоны к стандарту E.164.
   * Ведет учет последнего отправленного сообщения в `LAST_WA_DISPATCH`.
3. **`server/server.py`**:
   * Содержит эндпоинты:
     * `GET/POST /api/whatsapp/webhook` — универсальный прием сообщений от Meta и Green-API.
     * `GET /api/whatsapp/status` — JSON-мониторинг состояния шлюзов и последних 10 событий.
     * `GET /whatsapp` или `GET /api/whatsapp/qr` — готовая веб-страница с отображением живого QR-кода и статуса подключения.

## 4. Как возобновить работу в будущем (3 сценария)

Когда компания решит вернуться к автоматизации WhatsApp, поднять бота можно за 2-3 минуты по одному из сценариев:

### Сценарий А. Подключение через Meta Cloud API (Официальный и бесплатный до 1000 диалогов/мес)
1. В Facebook Business Manager подтвердить компанию Caravan Railroad (загрузить Гувохнома).
2. В Meta Developers ➔ **Настройка API** добавить постоянный корпоративный номер компании (`+998 95 157 8888` или `+998 91 034 10 55`).
3. Получить постоянный системный токен (System User Access Token).
4. В файле `whatsapp_bot/config.py` указать:
   ```python
   WHATSAPP_PROVIDER = "cloud_api"
   WHATSAPP_BOT_PAUSED = False
   WHATSAPP_TOKEN = "<НОВЫЙ_ПОСТОЯННЫЙ_ТОКЕН>"
   WHATSAPP_PHONE_NUMBER_ID = "<НОВЫЙ_PHONE_NUMBER_ID>"
   ```
5. Сделать `git commit && git push` — бот сразу заработает на официальном облаке Meta.

### Сценарий Б. Подключение через Green-API (Платный тариф ~$10/мес)
1. В кабинете `console.green-api.com` оплатить инстанс `710722751875` (тариф «Стандарт» или «Бизнес»).
2. В файле `whatsapp_bot/config.py` переключить:
   ```python
   WHATSAPP_PROVIDER = "green_api"
   WHATSAPP_BOT_PAUSED = False
   ```
3. Сделать `git commit && git push`.
4. Поскольку сессия `+998 91 034 10 55` уже авторизована, бот моментально начнет отвечать всем клиентам без ограничений.

### Сценарий В. Бесплатный собственный движок (Baileys / Open-Source)
1. Развернуть на Node.js легковесный мост Baileys на Render.
2. Пересылать вебхуки на локальный `/api/whatsapp/webhook`.
3. Поддерживает работу без подписок и сторонних сервисов.
